# Method demo data (fictional)

Reference data for [01_method_demo.ipynb](../../notebooks/01_method_demo.ipynb). It values
the synthetic results in `results-workbench/examples/data/example_study` and reuses that
example's `entities.csv` (wells -> field -> licence).

Companies, shares, prices, costs and tariffs here are **invented** to exercise the method.
Company A's shares equal the example's `working_interest` column. Nothing here describes
Alvheim, its licences or any agreement.
